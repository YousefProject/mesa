General

Cambiar la dirección de escucha reinicia el listener al guardar (sin reiniciar el proceso).

Correo (SMTP)

Deja el servidor vacío para desactivar el envío de correos. Si el servidor ofrece STARTTLS se usa siempre.

La prueba usa los valores del formulario sin guardar y envía a tu correo de cuenta.

Cómo funciona

Los ajustes se guardan en la base de datos y se aplican al instante: no hace falta reiniciar ./mesa.

Las variables de entorno SD_* solo se usan como valores iniciales antes de la primera vez que guardas aquí.

Si cambias el puerto y otro proceso lo usa, verás el error y el servicio sigue escuchando en la dirección anterior.
